# Data Analysis with Python

This repository contains my practical implementation for **Module 02: Data Analysis with Python** as part of my Data Science Virtual Internship.

## 📌 Project Overview
In this project, I explored real-world data handling workflows using Python's core data science libraries. The notebook demonstrates how to load raw tabular data, inspect data quality, clean missing values, and perform statistical aggregations.

## 🎯 Key Objectives Covered
- **NumPy Operations:** Creating arrays and performing fast numerical computations (mean, max, etc.).
- **CSV Dataset Handling:** Exporting DataFrames to CSV format and importing external CSV datasets into Google Colab.
- **Exploratory Data Analysis (EDA):** Inspecting dataset structure, summary statistics, and data types using `.head()`, `.info()`, and `.describe()`.
- **Data Cleaning & Imputation:** Identifying null values (`isnull().sum()`) and handling missing data using median, mean, and categorical imputation strategies (`fillna()`).
- **Data Aggregation:** Grouping data by categories (`groupby()`) to extract meaningful business insights.

## 🛠️ Tools & Technologies Used
- **Language:** Python 3
- **Libraries:** Pandas, NumPy
- **Environment:** Google Colab

## 🚀 Learning Outcomes
- Gained hands-on experience cleaning messy datasets containing missing values (`NaN`).
- Learned how to structure end-to-end data analysis pipelines in Jupyter/Colab notebooks.
